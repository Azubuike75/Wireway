# WireWay

**House wiring guide for Nigeria.** A free web app that walks you through wiring a house from chasing the walls to testing the finished job, with a circuit planner, a cable and breaker calculator, and illustrated install guides.

**Live app:** https://azubuike75.github.io/Wireway/

Produced by **Azubuike Christian Obiora**. A **Mythbborrn Press** production.

## What is inside

- **Walkthrough:** eight stages (plan, chase, conduit, plaster, cable, DB and earth, fit out, test) with steps, tools and warnings for four house types.
- **House plan:** rename, add and remove rooms, edit every point, and get the circuits, board size and materials list. Save named projects, export and import them, and export a PDF report with a cost estimate.
- **Connections:** labelled diagrams for the board, switches, sockets and the generator changeover.
- **Install guides:** air conditioner, water heater, CCTV, TV, lights, gate motor and solar panels.
- **Calculator:** breaker and cable size with heat and grouping derating, voltage drop, working shown step by step, and a saved history.
- **Reference:** cable, breaker and colour tables, and photos of real parts.
- Works offline after the first visit and installs to the home screen.

## Safety

WireWay is a planning and learning guide. Mains electricity can kill. A registered electrician must do or sign off the installation and test it before it is switched on. Figures follow common BS 7671 practice. Confirm local requirements with NEMSA or your distribution company.

## Files

| File | Purpose |
|---|---|
| `index.html` | The whole app, with its photos embedded |
| `sw.js` | Offline support. Raise the `CACHE` version number whenever `index.html` changes |
| `manifest.json` | Home screen install details |
| `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | App icons |
| `og.png` | Link preview image |
| `sitemap.xml` | For Google Search Console |
| `404.html` | Page shown for a wrong address |

## Updating

Upload the new `index.html` and `sw.js` together, then refresh the page once.
